# == Welcome To «Softlock» ==

«Softlock» is a turn-based strategy game, primarily aimed at two and more players.

Here in Softlock Civilization you either win nothing or lose everything.

«Softlock» is planned to feature several modes.

<p>Currently available modes include:</p>

<ul>
  <li><a href="#Legacy">Legacy</a></li>
</ul>


<h3 id="Legacy">= Legacy Rules =</h3>

Legacy is the classic mode in «Softlock».
Each player has a 8x8 field.

In one move player can either place a building on his own field or attack other player if possible.

If a rocket or a soldier hits a building, that building and the square it stands on are destroyed. After that, the player can no longer place any building on that square.

If the back wall of a field is attacked 8 times, the player loses the game.

Your goal is to protect your base and defeat the other players.

Here are all buildings in Legacy mode:

1. Barrack
The main building. It enables every other building within a radius of 1 square (non-diagonal). It can shoot soldiers.

2. Cannon
If it placed close to barrack, cannon can shoot rockets.

3. Trap
If it placed close to barrack, trap can block enemy soldiers.

4. Wall
If it placed close to barrack, wall can block enemy rockets.

# == Добро пожаловать в «Софтлок» ==

«Софтлок» - это пошаговая стратегическая игра, рассчитанная в первую очередь на двух и более игроков.

Здесь, в Софтлок цивилизации вы либо выигрываете ничего, либо теряете всё.

В игре запланировано несколько режимов.

Текущие доступные режимы игры:
<ul>
  <li><a href="#LegacyRU">Легаси</a></li>
</ul>
<h3 id="LegacyRU">= Правила Легаси =</h3>

Легаси — это классический режим в «Софтлоке».
У каждого игрока есть поле 8х8.

В один ход игрок может либо разместить постройку на своём поле, либо атаковать другого игрока, если это возможно.

Если ракета или солдат попадает в постройку, эта постройка и клетка, на которой она стоит, уничтожаются. После этого игрок больше не может размещать какие-либо постройки на этой клетке.

Если задняя стена поля подвергается атаке 8 раз, игрок проигрывает.

Ваша цель — защитить свою базу и победить остальных игроков.

Вот все постройки в режиме Легаси:

1. Казарма
<p>Главное здание. Она активирует все другие здания в радиусе 1 клетки (не по диагонали). Может стрелять солдатами.</p>

2. Пушка
<p>Если размещена рядом с казармой, может стрелять ракетами.</p>

3. Ловушка
<p>Если размещена рядом с казармой, может блокировать вражеских солдат.</p>

4. Стена
<p>Если размещена рядом с казармой, может блокировать вражеские ракеты.</p>
